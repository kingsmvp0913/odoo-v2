# 第 3 部 b 人工驗收清單（四種身分）

> 來源：2026-09-21 夜班的整枝審查。**以下沒有任何一項被實際執行過**——這台機器沒有瀏覽器。
> 全部需要人工在瀏覽器裡跑。標 ☀🌙 的項目淺色／深色各看一次。

---

## A. 平台管理員（`role='admin'`、無公司）

1. `/admin/users` → 「+ 新增使用者」，角色留「一般使用者」，填完送出。
   **夜班已修（Task 11），這裡要確認修好了**：應該要能選公司、能建成功。
2. 同頁找一個屬於某公司的帳號按「升為管理員」；再找一個管理員按「降為一般」。兩個方向都要成功。
3. 同頁確認**沒有任何帳號顯示「待審核」**（夜班已改詞彙），被停用的帳號應顯示「已停用」。
4. 更多工具：進行中 Pipeline／用量報表／架構圖／流程圖／公司管理／產品化規格／ODOO認證輔助 全部在。☀🌙
5. `/companies`：建一家測試客戶公司 → 綁一個專案 → 勾與不勾「可上正式」各存一次 →
   功能開關把 `exam`、`odoo_sync` 各開關一次，**每次存檔後重新整理再看一次值**
   （確認整包送出沒有把另一個開關順手關掉）。☀🌙
6. 解除綁定的確認框：要講出「N 位成員、M 張任務、包含他們自己開的任務、立即生效」。
7. `/company-users`（平台管理員沒有公司）→ 要是一句清楚的錯誤訊息，不是空白頁、不是一直轉圈。☀🌙
8. 開一個專案頁：六個分頁都在、測試環境四顆動作鈕都在、「上正式」在。☀🌙

---

## B. 內部員工（內部公司、`role='user'`）

1. ⭐ **最需要人眼確認的一項**：先完整登出，再用表單登入，**不要重新整理**。
   打開「更多工具」→「ODOO認證輔助」**應該要在**。
   如果不在、但重新整理後又出現 → 就是 store 只有一個寫入點那個缺陷（審查編號 I5）。
2. 更多工具裡不該有：進行中 Pipeline、用量報表、架構圖、流程圖、公司管理、產品化規格。
   帳號選單不該有「管理員」。☀🌙
3. 網址直打 `#/architecture`、`#/pipeline-flow`、`#/companies`、`#/task/1/terminal`
   → 四個都要停在站內 403 頁，網址不該被改寫成別套 UI。
4. 網址直打 `#/exam-run` → **應該進得去**（內部人員）。
5. 專案頁：只看得到 Chat／設定／測試環境／Wiki；測試環境分頁進得去但四顆動作鈕不見，
   「開啟測試區／查看 log／重新整理」還在。☀🌙
6. 網址直打 `#/projects/<id>?tab=repos`、`?tab=db`、`?tab=deploy` → 三個都要落回 Chat，
   **且中間不可以閃出管理員內容**（盯住第一幀）。
7. 「設定」分頁的「儲存」與「儲存對應」兩顆鈕——夜班修了 I1 之後**應該要看不到整個區塊**。
8. 任務頁：「執行歷程」圖示鈕應消失；「下載程式碼」應消失。
9. 專案清單右上「新增專案」——夜班修了 I2 之後**應該要看不到**。
   卡片 ⋮ 選單裡的「REPO」「連線設定」（M1，夜班可能未修）點了會落回 Chat。
10. 新手教學跑「專案」與「進度與通知」兩門課：記錄哪幾步出現置中、指不到東西的提示。
    **已知至少 `pd-repos`、`td-events` 兩步會壞**，這是待拍板項目，不是新問題。

## C. 公司管理員（客戶公司、`role='company_admin'`）

1. 帳號選單要有「公司帳號」；`/company-users` 進得去。☀🌙
2. 新增一個帳號（角色下拉只該有「一般使用者／公司管理員」，**不該有「管理員」**）→ 確認清單出現。
3. ⭐ **只有人能證的一項**：對**另一台瀏覽器正在登入中**的那個帳號按「停用」→
   回到那台，隨便點一個頁面，**確認它當下就被踢出**，而且看到的是
   「此帳號已停用，請聯絡貴公司的管理員」，**不是**「審核中」。
4. 再按「啟用」→ 確認能重新登入。
5. 專案的「上正式」：綁定勾了 `can_release` 的專案要看得到，沒勾的要看不到。
   側欄 ⋮、專案清單卡片 ⋮、專案頁三個位置都看一遍。
6. 個人設定 →「連線設定」分頁：夜班修了 I3 之後 **Odoo／eService 兩區應該要看不到**
   （GitHub PAT 區要留著，個人 GIT 所有人可用）。

## D. 客戶一般使用者（客戶公司、`role='user'`）

1. 登入頁：「還沒有帳號？註冊新帳號」——夜班修了 I6 之後**應該要看不到**。☀🌙
2. 側欄與更多工具：只該有 提意見／新手教學／設定／切換深淺色／登出；
   任何管理員項目都不該出現。☀🌙
3. 只看得到自己公司綁定的專案；任務列表只有自己的；沒有「顯示全部使用者」按鈕。
4. 網址直打別家公司的專案 id（`#/projects/<別家 id>`）→ 應是「專案不存在」，
   **不是 403，也不是空白**。
5. **公司停用情境**：請平台管理員在 `/companies` 把這家公司的 `is_active` 關掉
   （或把 `active_until` 設成昨天）→ 這個人重新登入。
   夜班修了 I4 之後應該要看到一句說明「公司帳號已停用或不在使用期間」，
   而不是一個空白的工作台。**測完記得把公司開回來。**
6. 深色模式把 A–D 每個新畫面（`/company-users`、`/companies`）再看一遍，
   特別看 pill、表格斑馬紋、紅色錯誤區塊。🌙
