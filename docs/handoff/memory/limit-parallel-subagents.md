metadata:
  type: feedback
---

09-17 做產品化第 3 部時，我為了「併行」同時開了 3 個背景 subagent（3.13 第 4 輪、3.14 修正、3.15 實作），外加每個都有審查輪。使用者原話：「開太多sub了」。

**Why:** 使用者前一刻問「沒有其他能併行的事嗎？」，我就一口氣開到 3 條線＋各自審查，超過他預期的規模；多條線同時回報也讓他更難跟上（他本來就要求決策題一題一題問，見 [[ask-decisions-one-at-a-time]]）。

09-17 晚些使用者又說「不要用sub了我token不夠」⇒ token 緊時完全不開 subagent，自己直接做（小步、少讀檔）。

**How to apply:** 預設同一時間只跑 1 個 subagent（實作或審查擇一）；使用者要求併行時最多加到 2 條，且先講清楚要開幾個。小修正與其開新審查輪，優先併進最後的整枝審查。
