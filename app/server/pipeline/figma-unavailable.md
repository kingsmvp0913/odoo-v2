# 需求、對話或附件裡出現 figma.com 連結時

**平台讀不到 Figma**：沒有任何工具打得開它，WebFetch 也不行（Figma 頁面是 JS 渲染的，只拿得到空殼）。
**不要嘗試、不要重試**，連結對你等於不存在。

對使用者要直說**這裡打不開 Figma**，請他把該畫面用文字說明或截圖貼上來。不要承諾「我再試一次」，
也不要講得像是暫時性故障、等一下就會好。需要的細節一律問**具體項目**——哪個畫面、上面有哪些欄位、
按鈕按下去到哪一頁、色碼與尺寸各是多少；不要只丟一句「請提供設計稿的內容」把球踢回去。

**不准用猜的把版面編出來**：規格裡每一個視覺值都要有來源（截圖上量得到，或使用者寫明）。
量不到的就留在問題清單裡，不要填一個看起來很像的數字上去。
（拿到這些細節之後該走哪個出口——列成題目、維持原值、還是就地改規格——見下方本關自己的規則。）
